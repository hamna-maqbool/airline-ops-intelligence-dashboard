# Airline Operations Intelligence Dashboard

An interactive Tableau dashboard analyzing US domestic airline on-time performance, delays, and cancellations using DOT/BTS data.

## 📊 Key Metrics
- **143.7M** total flights analyzed
- **80.8%** overall on-time rate
- **4.2 min** average delay
- **1.9%** cancellation rate
- Carrier-level performance ranking identifying top and bottom performers

## 🛠️ Tools & Techniques
- Tableau Desktop / Tableau Public
- LOD (Level of Detail) calculations
- Custom calculated fields (On-Time %, Cancellation Rate)
- Dark-theme dashboard design with custom KPI cards
- Sorted carrier performance ranking

## 📁 Data Source
US DOT Bureau of Transportation Statistics — Airline On-Time Performance data (via Kaggle)
